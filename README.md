# SwitchPrep

Free practice for switch-style logical reasoning tests used in many graduate job applications.

Work out which 4-digit code turns the input row of symbols into the output row. Practise untimed with step-by-step explanations, or try a 6-minute timed test.

**Play it here:** https://fhawes1.github.io/SwitchPrep/

Built by Felix Hawes.

*SwitchPrep is an independent practice tool. It is not affiliated with, endorsed by or connected to Aon or any employer. All questions are randomly generated.*
