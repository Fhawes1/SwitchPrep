How to solve it fast

  1. Take the first output symbol and find where it sits in the input. That number is the first digit.
  2. Rule out any option that doesn't start with that digit. Often only one is left.
  3. Two switches: apply the known switch to get the hidden middle row (or undo it if it comes second), then solve the other switch as normal.
  4. In the timed test, don't stall. If a question takes over 20 seconds, pick your best answer and move on.
